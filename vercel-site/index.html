This downloads the app source, not a one-click installer. Docker Desktop is required. The first setup downloads AI models and can take a while.

What it can do

  • ✓Upload and organize video projects locally
  • ✓Cut clips and export video files
  • ✓Transcribe speech and edit captions
  • ✓Analyze highlights and campaign requirements
  • ✓Run AI features with a local Ollama model

Start it locally

Install Docker Desktop, download and extract the source ZIP above, then open a terminal in the extracted project folder. Docker runs the app and its private Ollama service on your computer.

1. Start Clipper In PowerShell, from the project folder: 
docker compose up --build -d
2. Get the AI model Run once; the download may take a few minutes: 
docker compose exec ollama ollama pull qwen3:4b
3. Open the app Use the browser on the same computer: 
http://localhost:5000

Runs on your device

The Vercel website is only the download and information page. Video processing does not run on Vercel: the app runs locally, and project data is stored in the local data folder. Keep Docker running while jobs are processing. Don’t expose the local app to the internet; it does not have user accounts.

A modern computer and enough free disk space are needed for videos and AI models. CPU processing works but can be slow. Read the full setup and troubleshooting guide in the deployment guide.

Clipper is an open-source, self-hosted video tool. Each user runs their own private copy.
